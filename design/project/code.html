Context & Opportunity

Project Overview

crisis_alert

The Campus Problem

Shahjalal University of Science and Technology (SUST) serves over 10,000 enrolled students. The central cafeteria operated using manual paper tokens, handwritten counter ledgers, and cash exchange during condensed 90-minute meal cycles.

  • remove_circle_outline Queue Congestion: Long 35+ minute wait times during midday academic intermissions.
  • remove_circle_outline Reconciliation Deficits: Unaccounted paper token losses and frequent physical counterfeits.
  • remove_circle_outline Zero Demand Visibility: Kitchen staff cooked without dynamic real-time headcounts, causing severe inventory spoilage.
Pre-deployment Status
Manual paper book-keeping · 28% daily food variance
check_circle

The Architectural Solution

Engineered SustCafeteria: a unified web portal decoupling token issuance from fulfillment. The system provisions distinct interfaces for students, kitchen dispensing units, and senior university auditors with instant digital validations.

  • verified Single-Click Digital Vouchers: Time-stamped QR codes with automated single-redemption safeguards.
  • verified Real-time Kitchen Kanban: Live order queues updating pantry workers with exact headcounts.
  • verified Audit Reporting: Automated export of ledger transactions with relational consistency guarantees.

Production Guard Verification 
const jwt = require('jsonwebtoken');
const { RolePermissions } = require('../config/roles');

const verifyTokenAndRole = (requiredRole) => {
  return (req, res, next) => {
    const authHeader = req.headers.authorization;
    if (!authHeader || !authHeader.startsWith('Bearer ')) {
      return res.status(401).json({ error: 'AUTH_HEADER_MISSING_OR_MALFORMED' });
    }

    const token = authHeader.split(' ')[1];
    try {
      const decoded = jwt.verify(token, process.env.JWT_SECRET);
      req.user = decoded;

      // Verify role capability matrix
      if (!RolePermissions[decoded.role]?.includes(requiredRole)) {
        return res.status(403).json({ error: 'INSUFFICIENT_SYSTEM_PRIVILEGES' });
      }

      return next();
    } catch (err) {
      return res.status(403).json({ error: 'INVALID_OR_EXPIRED_TOKEN' });
    }
  };
};
